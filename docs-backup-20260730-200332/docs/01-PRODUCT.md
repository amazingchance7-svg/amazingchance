# Product Specification

Amazing Chance is a transparent online lottery platform centered on low-cost weekly participation and auditable draw execution.

## MVP objectives
- Sell tickets for USD 1.00.
- Run one draw each week.
- Allocate confirmed revenue deterministically.
- Select three weekly winners using verified external randomness.
- Preserve evidence sufficient to audit each draw.
- Accumulate a separate annual prize fund.

## Confirmed rules
Each confirmed ticket payment is allocated: 70% weekly prize pool, 20% company revenue, 10% annual prize fund.

The weekly prize pool is divided: first winner 50%, second winner 30%, third winner 20%.

A ticket becomes eligible only after confirmed payment. RANDOM.ORG is the only approved randomness provider. MVP has no customer deposit wallet.

## Open product decisions
Supported jurisdictions, age and identity verification, payment provider, refund policy, prize claim window, tax rules, annual draw rules, responsible gaming controls, and public verification interface.
